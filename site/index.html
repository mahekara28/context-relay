03 / A deliberate handoff

From a long conversation
to a clear continuation.

A handoff carries the reviewed state of the work. Every checkpoint keeps references back to the history it came from.

  1. 01

    Capture

    Connect a project. Discover matching sessions and choose what to import.

    relay sync --id CONNECTION_ID
  2. 02

    Review

    Choose evidence, current instructions, acceptance criteria and remaining work.

    relay ui
  3. 03

    Checkpoint

    Save an immutable snapshot. Resolve conflicting instructions before a merge.

    Sources + decisions + file hashes
  4. 04

    Continue

    Open a fresh session. Inspect the offered packet, then accept it through MCP.

    relay launch --id HANDOFF_ID

Interactive launch is available for configured Claude Code and Codex destinations. Every harness can use the copied prompt or Markdown export. Acceptance records delivery, not task completion.

A few useful answers

Before you relay.

Is this a hosted workspace?

This website introduces the project. Your actual workspace runs locally through relay ui. The website does not connect to your local service, collect conversations or run terminal commands.

Does it copy my entire conversation into a new agent?

You select source evidence and review a focused checkpoint containing the goal, current instructions, acceptance criteria and open work. Packets have a byte budget and disclose omitted evidence. Hidden model state is not transferred.

What is the difference between capture and MCP?

Capture adapters read a harness’s native history when requested. MCP lets a destination agent inspect Relay’s sources, retrieve a packet and accept an addressed handoff. Both use the same local service.

Do I need a Nebius API key?

No. Manual checkpoints and handoffs are keyless. Optional Nebius drafts require a configured key and model, an evidence preview, explicit consent, and your review of the result.

Does accepting a handoff mean the task is done?

No. Acceptance records delivery after checking the recipient, packet integrity, captured revisions and recorded file state. The receiving agent still needs to do the work and verify its results.

What does the beta support today?

A local npm CLI and workspace, four capture adapters, MCP access, checkpoint review and merging, handoff receipts, Markdown export, and interactive Claude Code/Codex launch. Install the public npm beta globally or run it with npx. Live model-quality evaluation remains pending.
