# Workspace captures

`thread-map.png`, `thread-review.png`, and `thread-connected.png` show the
current development thread map with synthetic Claude Code, Codex, OpenCode and
Goose sessions. The destination receiver remains offline, so the handoff is
shown accurately as queued. No native transcript, model call or task execution
is involved. Rebuild with `npm run build` followed by
`node scripts/npm/render-map.mjs` (set `RELAY_CHROME` when using an installed
Chrome executable).

## Published beta workspace demo

Generated by `npm run demo:render` against an isolated synthetic SQLite workspace. The flow selects a corrected seven-day retention instruction, reviews its sources, saves a checkpoint and offers a Codex handoff. No model calls or task execution occur. The GIF uses the same screenshots with playback timing set for readability.

Rebuild: `npm run demo:render`, then `python3 scripts/npm/build-demo-gif.py` (Pillow required). Use `RELAY_CHROME=/path/to/chrome` for an installed Chromium browser.
